Project 1: Utang na Loob: Student Finance Vault Tracker

UTANG NA LOOB: Student Finance Tracker is a console-based personal finance management application designed specifically to help students effectively monitor, organize, and control their financial activities. The system provides a centralized platform where users can create and manage their accounts, set monthly or semester-based budgets, and keep track of all academic-related and personal expenses in a structured manner. The application allows users to record daily expenditures such as food, transportation, school supplies, and other miscellaneous costs. It also includes features for tracking tuition payments and other educational fees, helping students stay aware of their remaining balances and payment schedules. All financial data is systematically stored and organized, allowing users to review their spending habits over time. In addition, the system provides a financial history feature that enables users to view past transactions and budget performance, making it easier to identify spending patterns and improve financial discipline. By offering clear insights into income allocation and expenses, the application encourages responsible money management among students. Overall, UTANG NA LOOB: Student Finance Tracker demonstrates practical application of Java programming concepts such as data handling, file storage, user input validation, and basic accounting logic, while promoting financial awareness and responsibility in a student-friendly way.

Project 2: Rock, Paper, Scissor! Game

The Rock, Paper, Scissors! Game is a Java-based client-server application that allows a player to compete against a computer or server-controlled opponent in a classic Rock-Paper-Scissors match. The system is designed with a networked architecture where the client handles user interaction while the server manages game logic, computer moves, and result evaluation. In addition, the game features a persistent leaderboard that stores and ranks player scores, encouraging competition among logged-in users. This allows players to compare their performance with others and strive to improve their ranking. Overall, the project demonstrates key concepts in Java programming such as client-server communication, user authentication, data persistence, and game logic implementation.

Project 3: Multi-Module Java System

This project is an integrated Java console application that combines several independent modules into one unified system. It includes a Cat Registration module, a Grocery/Product management module, a Movie Registration module, and two versions of a Quiz Bee game (Array-based and Stack-based). Each module is designed to handle a specific task, demonstrating different programming concepts such as data handling, user input processing, and basic data structures. The system is menu-driven, allowing users to easily navigate between modules and interact with each feature in a single program.
