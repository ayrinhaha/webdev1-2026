My Web Dev Journey

Week 1: Surviving HTML

Published on: June 9, 2026

Today I learned the basics of HTML and how it is used to create and structure webpages. I practiced using simple tags like headings and paragraphs to organize content, and I also got introduced to semantic elements that help give meaning to different parts of a page. Even though everything is still very basic, it was interesting to see how a webpage is built step by step using only code. Each tag has a purpose, and together they form the structure that we see in a browser.

What I found most exciting is how powerful HTML can be, even at a beginner level. It’s amazing to think that with just a few simple lines of code, you can start creating something that looks like a real website. This made me realize that web development is like building with digital blocks, where you can slowly create almost anything you imagine. This lesson made me more motivated to keep learning because it feels like the first step into being able to build and design things on the internet.

Semantics provide meaning, not style.
